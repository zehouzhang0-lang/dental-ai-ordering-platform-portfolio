# Private review notice

This repository is a sanitized, history-free portfolio snapshot intended for
authorized academic and professional review. It is not the operational
repository and must not be used to access, diagnose, or administer any live
environment.

The archive intentionally excludes production credentials, customer records,
patient or case evidence, deployment keys, raw acceptance media, database
dumps, signed file URLs, and the original Git history. Reviewers may inspect or
download the source within the access granted by the repository owner, but may
not redistribute it.
